## Nivel subterráneo — Parte 1

Unity **6000.3.16f1**, Windows nativo. El circuito provisional conecta `1-1` con
`1-2` y vuelve a `1-1`. Incluye ascensores, bloques rompibles, poderes conservados
entre escenas, animaciones de tuberías, fundidos y audio retro propio.

Controles: **A/D o flechas** para caminar, **Espacio** para saltar, **S** para
entrar a la tubería bonus y **D** para salir por conexiones laterales.

Consulta [la documentación de la parte 1](Docs/Parte-1-subterraneo.md) para conocer
las adaptaciones del original, regenerar recursos y ejecutar las verificaciones.
